Guides · The Desk Manual

The Heist guide: read the case like the desk.

The field manual for following the biggest story in gaming without getting played by it. Four habits, in the order the desk uses them.

  1. 1

    Start with what is confirmed

    The confirmed file separates what Rockstar has actually said from everything else. Redacted lines declassify on click, each one is a fact with a source, not a vibe.

  2. 2

    Check the date on everything

    The timeline is the spine of the case. Every claim gets pinned to when it was really said, because a two-year-old quote in a new thumbnail is how rumors are born.

  3. 3

    Weigh the exhibit

    The evidence board grades every item, confirmed, reported, rumored, and the grade travels with the claim wherever the desk repeats it. No grade, no weight.

  4. 4

    Know the desk's rules

    Commentary over credited official material and our own gameplay, only. Nothing here is ever dressed up as leaked or unreleased footage, if a video claims that, it is not ours, and it is not real until Rockstar says so.

Guides · Code in the box

Got the box, Redeem it

Some physical copies are code-in-box editions: no disc inside, just a printed download code. The code is the game, redeem it in your console's store and the download is yours. Here is the route on each system.

PlayStation

  1. Open the PlayStation Store.
  2. Select your profile icon at the top of the screen.
  3. Choose Redeem Code.
  4. Enter the 12-character code exactly as printed in the box.
  5. Confirm , the game lands in your library and the download can start.

Xbox

  1. Open the Microsoft Store.
  2. Open your profile menu and choose Redeem.
  3. Enter the code exactly as printed in the box.
  4. Confirm , the game lands in your library and the download can start.

Keep the printed code private , once a code is redeemed, it lives on that account. If a code fails, check every character against the insert before retyping; the stores read them exactly.
